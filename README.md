# Eros — English translation

An English translation of Giovanni Verga’s novel *Eros* (first published 1874–75), prepared from the public-domain fifth Treves edition (Milan, 1884).

The typeset book is:

- [`eros-translation/Eros_Giovanni_Verga_English.pdf`](eros-translation/Eros_Giovanni_Verga_English.pdf)

Rebuild from the chapter files with:

```bash
python3 eros-translation/build_pdf.py
```

The 2021 BUR critical edition that prompted this work is under copyright (introduction, notes, and apparatus by Giuseppe Traina / Mondadori). Only Verga’s novel text, which is in the public domain, has been translated.
