# CashEase Nigeria: Bank-Backed Machine Network Feasibility Study

PDF: [CashEase_Bank_Backed_Machine_Feasibility.pdf](CashEase_Bank_Backed_Machine_Feasibility.pdf)

This paper tests a bank-licensed machine network. It reuses the sourced inputs in `../cashease-v3` and does not edit that study.

Rebuild from the repo root of this folder:

```bash
python3 source/build_study.py
```

The script reruns `model/machine_model.py`, redraws the charts, writes `source/study.html`, and prints the PDF.
